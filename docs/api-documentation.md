# API documentation

Interactive documentation: **`/api/docs/`** (Swagger UI); machine-readable schema: **`/api/schema/`** (OpenAPI 3,
generated by drf-spectacular). This page explains the conventions shared by every endpoint.

## Authentication
| Endpoint | Notes |
| --- | --- |
| `POST /api/v1/auth/login/` `{email, password}` | Returns `{access, user, organization, role, permissions}` and sets the refresh token as an `HttpOnly; SameSite=Strict` cookie scoped to `/api/v1/auth/`. Rate-limited per IP. |
| `POST /api/v1/auth/refresh/` | Uses the cookie; rotates it (the old one is blacklisted). Rejects foreign `Origin`s. |
| `POST /api/v1/auth/logout/` | Blacklists the refresh token and clears the cookie. |
| `GET/PATCH /api/v1/auth/me/` | Session payload; PATCH `full_name`, `phone`, `date_display_mode`, `default_organization`. |
| `POST /api/v1/auth/change-password/`, `/password-reset/`, `/password-reset/confirm/` | Password management (reset responses never reveal whether an account exists). |

Send `Authorization: Bearer <access>` and **`X-Organization-ID: <id>`** on every other call. A user who is not an
active member of that organisation receives 403.

## Errors
```json
{"detail": "Please correct the highlighted fields.", "code": "validation_error",
 "errors": {"lines": [{"quantity": ["Quantity must be greater than zero."]}]}, "request_id": "9ffe…"}
```
| HTTP | Meaning |
| --- | --- |
| 400 `validation_error` | Field errors in `errors` (nested for lines). |
| 401 | Missing/expired access token (call `/auth/refresh/`). |
| 403 | Not a member of the organisation, or the role lacks the permission named in `detail`. |
| 404 | Not found **or belongs to another organisation**. |
| 409 business rule | `code` is one of: `period_locked`, `fiscal_year_closed`, `no_period`, `no_fiscal_year`, `duplicate_posting`, `insufficient_stock`, `over_fulfilment`, `over_invoicing`, `over_receipt`, `over_billing`, `over_return`, `over_allocation`, `invalid_allocation`, `credit_limit`, `unbalanced`, `duplicate_supplier_invoice`, `fiscal_year_overlap`, `close_blocked`, `not_editable`, `protected`, `integrity`. |

## Lists
Paginated: `{count, page, page_size, num_pages, results}`; `?page=&page_size=` (≤500), `?search=`, `?ordering=field`
or `-field`, field filters (e.g. `?status=POSTED&customer=12`, `?status__in=DRAFT,SUBMITTED`) and the date filters
in `calendar-and-date-rules.md`. Most lists offer `GET …/export/?export=csv|xlsx` with the same filters.

## Dates
Responses include `<field>` (AD) and `<field>_bs`. Requests may send either.
